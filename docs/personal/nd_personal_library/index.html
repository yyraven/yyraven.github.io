数据分析

哪些天不是读书天

看看啥时候我最不务正业吧。

比大时代晚了千分之一秒

“你和我出生在尘埃落定后的时代，晚了千分之一秒” ——乔伊斯（极乐迪斯科）

看看我到底是时代的弄潮儿还是活在20世纪的老古董？

看书比较平均，60年代较多，这也确实是我想要的；电影看的都是最近上映的（本来就并非狂热电影迷）；音乐嘛，我是狂热的80-90年代爱好者，这确实也体现出来了…

我是一个慷慨的打分者吗？

打分一般遵循这个原则：“有无法忽视的问题” - 5分及以下，“无聊但合格” - 6分，“还不错” - 7分，“蛮喜欢” - 8分，“超喜欢” - 9分，“我愿意对出门后遇到的每一个人卖安利” - 10分。

——我是一个慷慨的打分者吗？从统计数据的角度上，是的。因为一般只有好看才会看完吧。对于书尤其如此，看不下去的我就不会看完（这是一个坏习惯），所以也不会记到这里。
